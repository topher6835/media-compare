- JPEG/PNG SMALL_THUMBNAIL generation/publication, serving, and item/group-summary frontend browsing are implemented. The existing catalog Source/context trust profile remains local macOS/APFS.

No durable review decisions or Trash/delete/move operation exists; future execution must revalidate immediately before mutation. Only the existing local macOS/APFS authority profile can pass preflight; other profiles fail closed.
