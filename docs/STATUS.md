Independent observations after a file handle closes create new FileEntries and distinct ContentRecords even if bytes match; the same retained observation may serve overlapping memberships. Superseded ACTIVE routes are retired without a missing claim. Reacceptance itself changes no membership; catalog/cache history stays readable without live authority. No exFAT API/UI, rebind UI or Windows relocation implementation was added.
